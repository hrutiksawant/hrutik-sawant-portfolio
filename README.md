# 🚀 Hrutik Sawant | Personal Portfolio

A modern, highly professional, MNC-level personal portfolio website built with clean HTML5, advanced CSS3 (Multi-color Neon Theme & Custom Animations), and interactive JavaScript.

## ✨ Features
- **Modern UI/UX**: Multi-color neon glow themes (Cyan, Pink, Purple, Green) with glassmorphism effects.
- **Responsive Design**: Fully optimized for mobile phones, tablets, and desktop displays.
- **Interactive JavaScript**: Mobile menu toggling, scroll-spy active section highlighting, and sticky header behavior.
- **Optimized Profile Rendering**: Custom image styling with cutout drop-shadow effects.

## 🚀 Featured Projects
1. **RedStore - E-Commerce Web App**: A responsive 7-page e-commerce platform built with HTML5, CSS3, and JavaScript featuring real-time search, sorting, secure auth, and cart management.
2. **Automated CI/CD Web App Pipeline**: CI/CD deployment pipeline utilizing Docker, Jenkins, and AWS cloud infrastructure.
3. **Fresh Chicken Delivery Web App**: Interactive menu selections, product filtering, and cart management scripts.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Icons**: Boxicons
- **Hosting / Deployment**: Vercel / GitHub
